# Sistema de Agendamento de Quadra de Futebol

**Última revisão:** 05-2025

Aplicação web completa para gestão de aluguel de quadra society, com landing page moderna, sistema de reservas online, pagamentos via PIX e painel administrativo para controle de clientes e horários.

> Projeto de demonstração — desenvolvido apenas para fins de estudo e portfólio. Não representa um sistema comercial ativo.

## Funcionalidades

- Landing Page Responsiva  
  - Slider de eventos (Rachão, Escolinha, Aniversário)  
  - Apresentação da equipe e da estrutura  
  - Sessão “Sobre nós”, pacotes e serviços  

- Sistema de Reservas  
  - Seleção de data em calendário interativo  
  - Visualização de horários disponíveis/ocupados  
  - Múltiplas horas selecionáveis  
  - Resumo automático com cálculo de valores  
  - Geração de pagamento via PIX (checkout integrado)  

- Painel do Administrador  
  - Gestão de quadras, clientes e reservas  
  - Bloqueio de horários  
  - Consulta de pagamentos  

- Recursos extras  
  - Integração com WhatsApp para contato rápido  
  - Loader animado com ícone de futebol  
  - Responsividade para desktop, tablet e mobile  

## Tecnologias Utilizadas

- Frontend: HTML5, CSS3, JavaScript (ES6+)  
- Backend: PHP 8+  
- Banco de Dados: MySQL 8+  
- Bibliotecas:  
  - Bootstrap 4.6  
  - Font Awesome 6  
- Pagamentos: Integração PIX via PHP
